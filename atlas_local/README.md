# Atlas Local

Premium local SEO and Google Maps optimization agency homepage.

## Stack

- Next.js 15 App Router
- TypeScript
- Tailwind CSS
- Framer Motion
- Lucide React
- Geist (font)

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build
```

## Project Structure

```
app/           — Pages and layouts
components/    — React components
lib/           — Utilities
 types/         — Shared types
public/        — Static assets
```

## Notes

- Uses `geist` package for typography. Install with `npm install geist`.
- All animations are restrained (fade, slight translate, opacity only).
- Mobile-first responsive design.
- Semantic HTML throughout.
